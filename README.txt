# AliZoVoX × NekoHiRaN

## فایل‌ها
- `index.html` سایت اصلی
- `config.json` اطلاعات و لینک‌ها
- `admin.html` پنل ساده و بدون نیاز به برنامه‌نویسی
- `assets/` عکس‌های پروفایل

## استفاده از پنل
1. `admin.html` را باز کن.
2. نام/عنوان/لینک‌ها را تغییر بده.
3. روی «دانلود config.json جدید» بزن.
4. در GitHub فایل `config.json` را با فایل جدید جایگزین کن.
5. GitHub Pages بعد از انتشار، سایت را با اطلاعات جدید نشان می‌دهد.

## نکته
GitHub Pages استاتیک است. برای اینکه پنل بتواند بدون آپلود فایل مستقیماً روی سایت آنلاین ذخیره کند، باید یک سرویس ذخیره‌سازی/احراز هویت جدا اضافه شود. این نسخه عمداً بدون توکن و اطلاعات حساس ساخته شده تا امن و رایگان بماند.
